## External medical data

- **OAI:** the Raptor author reports masked external supervision from approximately
  2,399 baseline knees ([discussion 746792](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/746792)).
  This is an upstream statement, not our independently audited raw-data count.
  No OAI data, identifiers or derived row-level records are in this package.
- **SKM-TEA:** the active public R6 anchor and the proposed S6 path use an anatomical
  `anatomy.pt` V-Net. This is external medical-data lineage and must be declared.
  No anchor weight or training data is redistributed.
- **fastMRI:** R7 history and R6 provenance are not interchangeable. The available
  R6 manifest did not establish absence of fastMRI. This remains UNKNOWN.
- **KneeXNet:** mentioned by an upstream helper package; complete active indirect
  lineage was not resolved. We do not equate package inventory with execution.
- **Own A/T/F/G/Z:** RSNA images and CC0 soft labels, plus ImageNet initialization;
  no external medical-image branch in the final Own models only system.

## Gold58-derived anchor rules

S6's fixed v2/v4 anatomical anchor rules explicitly have Gold58 montage-development
provenance. Their use as fixed code was authorized with disclosure during feasibility.
No Gold58/Expert images, labels or reference values were opened for this adaptation
or used to tune it. S6-CC0 never reached a training epoch and is not in the final
slots. This statement is not an assertion that all upstream public artifacts were
developed without gold-derived choices.

## Own source and changes

`SOURCE_MANIFEST.json` records hashes of the own source modules from the experiment
archive. Publication changes extract scientific definitions, rename imports,
replace private Colab input/Drive launchers with an explicit local adapter, and
expose fixed-family inference. The model/augmentation/optimizer definitions are
retained. New adapters are marked as such and have not reproduced historical GPU
results. Copyright 2026 the RSNA Knee Ensemble contributors. Own source is Apache-2.0.

No upstream dataset or checkpoint is relicensed by the root LICENSE. Unresolved
artifact-version or lineage facts remain stated uncertainties, not invented pins.

## KneeMRI illustrative slices (separate image license)

Example MRI slices on the project page are from the KneeMRI dataset, Clinical Hospital Centre Rijeka, Croatia (Štajduhar et al., Computer Methods and Programs in Biomedicine, 2017), licensed CC BY-NC-ND 4.0. They are not competition data and were not used for training.

- Dataset: https://zenodo.org/records/14789903
- Image license: https://creativecommons.org/licenses/by-nc-nd/4.0/
- Paper: https://doi.org/10.1016/j.cmpb.2016.12.006

This attribution is prepared for the requested local illustrative assets. It does not change the images' license to the code's Apache-2.0 license. Site insertion and publication are separate actions; `docs/index.html` is unchanged in this preparation task. The permitted preparation is a single volume-wide grayscale display conversion with original spatial dimensions, without cropping, resizing, rotation, annotation, colorization or channel combination.
